# career-advisor
used streamlit for frontend and python  backend . suggests careers on basis of your input
database is just dictionaries
it is an interactive frontend-based career recommendation system that analyzes a user’s profile and suggests the most suitable career paths using a weighted scoring algorithm.

The application collects detailed inputs such as technical skills, industry interests, personality traits, preferred work environment, and expected salary. It then compares this data with a structured career database and evaluates compatibility using multiple dimensions including skill match, trait alignment, salary expectations, and work environment preferences.

The core of the system is an analytical engine that assigns weightage to each factor (skills, traits, environment, and salary) and computes a final compatibility score for each career. Based on this score, the system ranks and recommends the best-matching career options.

Additionally, the project provides:

* 📊 Visual insights using radar charts and bar graphs
* 🧠 Skill gap analysis to identify missing competencies
* 📚 Personalized upskilling paths for improvement
* 📈 Market demand and future scope insights for careers

This project demonstrates the practical application of data structures (arrays, sets, dictionaries) and algorithmic thinking to build an intelligent decision-support system in a real-world scenario.
